# Визуальная и интерактивная система

Цель: тёплый, спокойный интерфейс без потери возможностей Tan Ata.
Референс: светлый cream/terracotta концепт Kimi ccbe5df; это не законченный мобильный дизайн.
Название Amio временное: одноимённый продукт найден, использовать перед запуском нельзя без проверки.

## Навигация
Нижняя панель: Сегодня / Чат / центральное сердце / Вместе / Мы.
Сердце «Думаю о тебе» остаётся по центру как действие, не вкладка.
Вместе содержит письма, разговоры, игры, задачи, календарь и желания; Мы — историю, настройки и приватность.
Настройка быстрых кнопок не убирает сердце и доступ к чату.

## Сердце
- Нежная пульсация только при разрешённых анимациях, без обязательного haptic.
- Respect Reduce Motion: статичная иконка; доступная текстовая подпись.
- После нажатия состояния: отправка / отправлено / офлайн / ошибка с повтором.
- Не показывать «доставлено», пока нет подтверждения доставки.
- Защита от серии случайных нажатий и понятная cooldown-подсказка.
- Нельзя начислять штрафы и показывать обвиняющие счётчики за отсутствие ответа.

## Экран Сегодня
Приветствие, необязательный countdown встречи, письмо, вопрос/настроение, ближайший план.
Если пары пока нет — приглашение; если нет разлуки — общая дата/план вместо пустого countdown.
Карточки открывают реальные сценарии, а не создают иллюзию отправки.

## Система компонентов
Tokens: фон/поверхность/текст/акцент/ошибка, 4/8-based spacing, размеры шрифта, radii, motion.
Проверять контраст текста 4.5:1, крупного текста 3:1; цвет не единственный маркер состояния.
Touch targets минимум 44pt iOS / 48dp Android; Dynamic Type и screen reader labels обязательны.
Клавиатура не закрывает composer; учесть safe areas, длинный текст, маленькие экраны и поворот.
У каждого экрана: loading, empty, success, error, offline, access revoked.

## Локализация
Все продуктовые строки RU/EN, без конкатенации грамматических фрагментов.
Даты, числа, валюты, plurals форматируются по locale, часовой пояс независим от языка.
EN проверяется на реальном экране, не только наличием ключей. Приватный контент не переводится автоматически.

## Приёмка
Скриншоты iOS/Android в двух языках; путь с клавиатурой; screen reader; reduce motion;
reconnect; повторное действие; выход из modal/back без потери несохранённого текста.
Не объявлять экран готовым по сгенерированной картинке.
