# Реестр решений

## Принято
- D01 Expo/React Native/TypeScript для двух мобильных ОС; RU/EN.
- D02 Tan Ata как источник сценариев и разрешённого нейтрального кода, не production-данных.
- D03 Приватный чат — P0 наряду с парой, письмами и сердцем.
- D04 Дизайн сохраняет сердце по центру; можно менять другие быстрые действия.
- D05 ≤600 строк, ≥90% coverage всех production-модулей, независимая приёмка.
- D06 Облако, отдельные ветки, никаких force-push/перезаписи Kimi.

## Предложения, требуют технического решения перед соответствующим этапом
- D07 Модульный backend + PostgreSQL + outbox: см. Architecture.md.
- D08 Общий бюджет — учёт расходов, не открытие финансового счёта.
- D09 Базовое общение не ограничивать часами, не обещать абсолютную доступность.

## Открыто и блокирует запуск, но не разработку на синтетических данных
- Первый рынок, возраст аудитории и регион хранения.
- Auth-провайдер, восстановление аккаунта, бюджет инфраструктуры.
- E2EE для чата/писем: аудит готового протокола, управление устройствами, потеря ключей.
- Экспорт общего архива, сроки резервных копий, удаление и выход из пары.
- Окончательное название после проверки магазинов, доменов и товарных знаков.
- Правила платного доступа и магазинных покупок, юридические документы.
