# Карта переноса Tan Ata

Источник ядра уже зафиксирован в FOUNDATION.md: 4822e213e991f6e8c0177751e0fd6626b1f237bc.
Это восстановленная карта по сохранённым результатам исследования и GitHub Foundation.
Полный исходник каждого модуля нужно повторно проверить перед переносом. Не считать таблицу аудитом всего кода.

## Запрещённый перенос
Общий код доступа, фиксированные две личности, production-ключи, дампы, персональные тексты/изображения,
Telegram chat IDs, исходная история Git и публичные URL приватных файлов.

## Порядок каждого переноса
Исходный файл и SHA → лицензия/авторство → нейтрализация → чистая логика → ACL и новые контракты →
регрессия существующего поведения → тесты двух пар → UI RU/EN → независимая приёмка.
Нельзя скрыто заменить полноценный сценарий статичной карточкой.
