# Pairspace

Новое приложение для пар: письма, ожидание встречи, общие воспоминания и помощь замечать важное в словах друг друга.

**Статус: начальная основа разработки, не готовый сервис.** Регистрация, база, платежи, уведомления и ИИ пока не реализованы. Стартовая страница не собирает данные.

## Откуда начинаем

Фундамент — собственный проект [tan-ata](https://github.com/bairasbai/tan-ata). Здесь новая история Git и отдельная архитектура для множества пар. Личные письма, фотографии, аккаунты и настройки продакшена не перенесены.

- Нынешняя база: [4822e21](https://github.com/bairasbai/tan-ata/tree/4822e213e991f6e8c0177751e0fd6626b1f237bc).
- Ранний дизайн: [cc8fb16](https://github.com/bairasbai/tan-ata/tree/cc8fb168bf6bdc4be38647906f97319d3abe75af).
- Перенесённое ядро и изменения: [docs/FOUNDATION.md](docs/FOUNDATION.md).

## Что уже есть

- Адаптивный интерактивный UI-концепт «Рядом» на Next.js App Router; все данные в демо вымышленные.
- Нейтральные функции календарных дат и текста из исходного проекта.
- Ядро разлук: даты, пересечения и открытие письма в часовом поясе получателя.
- Тесты ядра без базы, сети и установленных зависимостей.
- [Продукт](docs/PRODUCT.md), [архитектура](docs/ARCHITECTURE.md), [план работы](docs/ROADMAP.md).

## Проверка и запуск

Node.js 22.18+; `npm test` запускает тесты ядра без `npm install`.

Для интерфейса: `npm install`, затем `npm run dev`. Lockfile добавлен в репозиторий. Перед развёртыванием проверяются `npm run typecheck`, `npm test` и `npm run build`.

Скопируйте `.env.example` в `.env.local` только при реализации соответствующего этапа. Сейчас приложению не нужны ключи и база. Реальные значения не публикуйте.

## Следующий этап

Действующий личный сайт `tanata.vercel.app` — отдельный проект. Этот репозиторий к нему не подключён.
