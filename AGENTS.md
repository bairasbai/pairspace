# Правила Pairspace

- Это новый самостоятельный продукт, не личный сайт исходной пары.
- Общение с Александром — по-русски. Не объявлять запланированное реализованным.
- До изменения Next.js читать соответствующие документы установленного `node_modules/next/dist/docs/`.
- Персональные данные, фото, письма, секреты, дампы и историю Git исходного сайта не переносить.
- Подключение к исходной production-базе и выкладка в исходный Vercel-проект запрещены.
- Личности — отдельные users; отношение к паре — memberships. Пол не является идентификатором аккаунта, правом доступа или условием оплаты.
- Каждый ресурс пары должен иметь couple_id. Доступ определяется сервером по сессии и действующему членству; одного ID из URL недостаточно.
- До реальных пользователей обязательны тесты изоляции двух разных пар, файлов, фоновых задач и уведомлений.
- ИИ обрабатывает только разрешённые открытые данные. Личные черновики и запечатанные записи исключаются. Выводы содержат источники и различают факты/гипотезы; человек может их исправить.
- Помощник предлагает черновики. Отправка от имени пользователя требует явного действия пользователя.
- Подписка относится к паре, плательщик — любой участник. Цены пока гипотезы. Платежи и автопродления не включать без отдельного согласования.
- README и ROADMAP должны отражать фактический статус. Не добавлять фиктивные работающие кнопки.
- Не создавать лишние копии и зависимости. Свои временные результаты и процессы убирать после проверки. Не трогать чужие процессы/работу.
- GitHub: сначала локальный git; запросы последовательно; при 403/429/Bad credentials остановиться. Без частого опроса и массовых issue/PR.
